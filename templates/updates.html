📖 Manual Update Instructions

If automatic updates don't work, you can update manually:

Option 1: Using Git Command Line

cd {{ app_path }}
git pull origin main
sudo systemctl restart cybersec-news  # If using systemd
# OR
sudo systemctl restart apache2  # If using Apache

Option 2: Re-download from GitHub

cd {{ app_path }}
# Backup your database first!
cp cybersec_news.db cybersec_news.db.backup

# Pull latest changes
git fetch origin
git reset --hard origin/main

# Restart application
python app.py  # Or restart service

Safety Tips

  • ✅ Always backup your database before major updates
  • ✅ Check for local changes before updating
  • ✅ Review update notes in CHANGELOG.md
  • ✅ Test updates in development before production
  • ⚠️ Automatic updates may require application restart

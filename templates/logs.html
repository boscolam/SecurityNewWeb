💡 Troubleshooting Tips

Error Log (error.log)

  • Check for Python tracebacks and exceptions
  • Look for "CRITICAL" or "ERROR" level messages
  • Common issues: Permission denied, Module not found, Database locked

Update Log (update.log)

  • Shows git pull operations and results
  • Check for merge conflicts or failed updates
  • Service restart status after updates

Feed Log (feed.log)

  • RSS feed fetch successes and failures
  • Check for timeout errors or invalid feeds
  • Look for specific source names if feeds not updating

Access Log (access.log)

  • HTTP requests to the dashboard
  • Check for unusual activity or errors
  • Monitor API endpoint usage

Log Levels

  • CRITICAL - Serious errors causing failure
  • ERROR - Errors that need attention
  • WARNING - Warnings about potential issues
  • INFO - Informational messages
  • DEBUG - Detailed debugging information
